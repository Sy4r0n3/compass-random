# #コンパス ランダムデッキ抽選器（PWA版）

## 公開方法
PWAとしてホーム画面にインストールするにはHTTPSで公開する必要があります。ZIPを展開し、フォルダ内のファイル一式を静的ホスティングへアップロードしてください。

### GitHub Pagesで公開する場合
1. GitHubで新しいPublicまたはPrivateリポジトリを作成。
2. このZIPを展開し、`index.html`、`manifest.webmanifest`、`sw.js`、`icons`フォルダをリポジトリの最上位にアップロード。
3. リポジトリの Settings → Pages → Deploy from a branch を選択し、`main` / `root` を指定して保存。
4. 公開された `https://...github.io/.../` のURLをAndroidのChromeで開く。
5. Chromeのメニューから「アプリをインストール」または「ホーム画面に追加」を選択。

## データについて
キャラクター一覧・所持カードはブラウザのlocalStorageに保存されます。ブラウザのデータ消去やアプリ削除に備え、アプリ内の「JSONを書き出す」で定期的にバックアップしてください。アプリをインストールした後も、同じ公開URL・同じブラウザストレージ内で使ってください。

## 注意
- このフォルダは静的PWAです。アカウント同期やクラウド保存はありません。
- 既存HTML版の機能を引き継ぎ、キャラクター一覧は今回提供された102名を初期登録しています。
